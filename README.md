# NYC Permit Lead Scanner

A tool that finds new renovation jobs for a Brooklyn kitchen showroom.

**What it does.** Every day it reads new NYC building permits from the city's open data, picks the kitchen and bath jobs, and drafts a short personal note to each owner or contractor. I read every note and send each one myself.

**Result.** More than 20 notes sent since late October 2026, and contractors write back.

**Built with** Claude, NYC Open Data, hosted on Vercel.

The code is private because it works with contact details.
